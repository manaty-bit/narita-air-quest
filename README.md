# NARITA AIR QUEST（2026年度・成田空港宿泊研修用）

中学1年生が、航空機・空港の仕事・成田空港の歴史・空港の未来を楽しみながら学べる4択クイズアプリです。

## 公開URL

https://manaty-bit.github.io/narita-air-quest/

## 収録内容

- 全94問（★難問35問）
- 各問題に4択、正解、基本解説、任意で開ける「さらに深掘り」、出典URL
- 生徒個人名は公開していません

## ゲームモード

### 連続正解チャレンジ
- 出題ジャンルを選べます（すべて／個別ジャンル）
- 選んだジャンル内で、問題を重複なくランダム出題
- 1問間違えたら終了
- 正解するとコンボが増え、称号・フライトメーターの演出があります
- 自己ベストのみ、その端末のブラウザの `localStorage` に保存されます

### 10問の学習モード
- 全94問から10問を抽出：通常問題6問、★難問4問
- それぞれの組から重複なしで抽出し、10問の出題順もランダム
- 不正解でも終了せず、必ず10問目まで進めます
- 正解数を表示します。コンボ記録・自己ベストには影響しません
- 答えと解説が表示されるのは、実際に回答した各問題だけです
- 10問すべての解答を一度に見る画面や、未出題問題の答え一覧はありません
- 「別の10問を学習」で新たに10問を抽出します（以前の回の問題が出る場合はあります）

## 解答と復習

- 問題と選択肢の順番をそれぞれランダム化しています
- 回答を確定すると、正解位置を色で示し、基本解説を表示します
- 「さらに深掘りしてみよう」を開くと、補足の背景と出典リンクを表示します
- 解説が長いときは、読めることを優先してスクロールできます

## 運用上の注意

**このリポジトリはPublicです。** クイズのデータと解答は `questions.js` に含まれており、GitHubやブラウザの開発者ツールで閲覧できます。学習モード内で未出題問題の答えを隠すことはできますが、公開Webアプリで解答を技術的に秘密にすることはできません。成績評価や厳密な不正対策が必要な競争には、この構成を使わないでください。

生徒のフルネーム・学籍番号・個人の成績データなどは公開しないでください。リンク先の資料も公開前に確認してください。
